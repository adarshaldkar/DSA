# C++ and Python DSA Repository

This repository contains organized Data Structures & Algorithms (DSA) practice solutions implemented in both **C++** and **Python**.

---

## 📁 Repository Structure

### 🟦 C++ (`CPP/`)
* **`01_Basics/`**: Syntax, fundamental loops, arithmetic, and basic math/string conversions.
* **`02_Patterns/`**: Star and number pattern problems.
* **`03_Arrays/`**: Array manipulation, min/max finding, subarray analysis, and merging.
* **`04_Strings/`**: String manipulation and reversal problems.
* **`05_TwoPointers/`**: Two-pointer techniques (Two Sum, 3Sum, Remove Duplicates, Sorted Squares).
* **`06_SlidingWindow/`**: Fixed & variable size sliding window problems (e.g. Max Sum Subarray of Size K).

### 🐍 Python (`Python/`)
* **`01_Basics/`**: Basic loops, range operations, arithmetic, and conversions.
* **`02_Arrays/`**: Array problem implementations.
* **`03_TwoPointers/`**: Two-pointer implementations with multiple approaches (Brute Force, Hash Map, Two Pointers, Comprehensions).
* **`04_SlidingWindow/`**: Sliding window pattern problems.
